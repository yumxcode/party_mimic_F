## 3. 判定口径

- 回放从每段第 0 帧开始，根位姿/关节取参考值，根速度取参考值，策略用 ONNX 推理，物理 0.005 s × 4 = 0.02 s 控制周期。
- A2 的"局部"误差：机器人与参考各自转到自身骨盆航向系后比较 tracked body 位置（与 sim2real leaderboard 口径一致）。
- A4/A5 在**回放轨迹**上用与重定向门相同的定义重算（`tools/check_motion_f1.py` 的 gate 7/9 公式）。
- 每段独立判定；4 段全过才算舞蹈门通过。
