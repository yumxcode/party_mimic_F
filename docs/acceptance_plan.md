## 2. 通过指标与阈值出处

| # | 指标 | 阈值 | 出处 |
|---|---|---|---|
| A1 | 跌倒 | 0/4 段（base z > 0.25 m 且倾角 < 0.8 rad，全程） | 通用稳定判据；PartyMimic 训练终止条件同口径 |
| A2 | 局部 body 位置误差（骨盆航向系） | 训练段 ≤ **50 mm**；held-out ≤ **80 mm** | PartyMimic 公开的 G1 held-out 误差为 21–51.5 mm（41 h 库）；本项目库仅 76 s，训练段取其最差 split 的 51.5→50 mm，held-out 放宽到 80 mm |
| A3 | 关节跟踪误差 | ≤ **0.20 rad**（训练段） | 此前 F1 舞蹈线 sim2sim 实测 0.1467–0.1518 rad（5k 迭代，另一方法）；取 0.20 作为上界 |
| A4 | 回放脚底平贴率（支撑期） | 左右脚均 ≥ **90%** | 与重定向门 7 同阈值（用户明确关注"踮脚/侧脚"） |
| A5 | 回放双腿 hip roll 同时内收帧占比 | ≤ **3%** | 与重定向门 9 同阈值（用户明确关注"hip roll 内收"） |

**通过条件：A1–A5 全部满足。** 任一项不满足即判定未通过，报告中如实列出。

## 3. 判定口径

- 回放从每段第 0 帧开始，根位姿/关节取参考值，根速度取参考值，策略用 ONNX 推理，物理 0.005 s × 4 = 0.02 s 控制周期。
- A2 的"局部"误差：机器人与参考各自转到自身骨盆航向系后比较 tracked body 位置（与 sim2real leaderboard 口径一致）。
- A4/A5 在**回放轨迹**上用与重定向门相同的定义重算（`tools/check_motion_f1.py` 的 gate 7/9 公式）。
- 每段独立判定；4 段全过才算舞蹈门通过。

## 4. 明确不做的事

- 不用训练时的 reward 或世界模型误差代替 sim2sim 指标。
- 不在看到结果后调整阈值；若未通过，报告实测值与差距。
- 不把 Tier B 片段或行走片段计入通过门。
